A `die <code> <detail> [status]` helper prints `fetch-pin: <code>: <detail>` to stderr. Defaults: pins `<repo>/pins.txt`, root `<repo>/.fixtures`, repo from `cd "$(dirname "$0")/.." && pwd -P`. Steps in order, following the RESEARCH prototype:
1. Parse options; any unknown option, a missing value, or not exactly one dest prints `usage` (exit 2).
2. Validate the requested dest with `check_dest` (allow-listed charset; IFS=/ split with no empty, `.`, or `..` part; no leading slash): `bad-dest`.
3. pins file absent or unreadable: `missing-pins` (exit 2).
4. Read the pins file line by line with `while IFS= read -r`, skip comments and blank lines; every other row must split into exactly three whitespace-separated fields (`bad-row: line <n>`); select rows whose third field equals dest; none is `no-row`, more than one is `bad-row: duplicate dest`. Row text is only ever used as quoted arguments and in `case` patterns, never evaluated.
5. Digest must be 64 lowercase hex (`bad-digest`); the row dest must pass check_dest (`bad-dest`).
6. Scheme: `https://*` sets proto `=https`; `file://*` sets `=file` only when `GBL_FETCH_ALLOW_FILE` is exactly 1, else `bad-url`; anything else `bad-url`; a URL holding whitespace, a quote, or a backslash is `bad-url`.
7. The curl program is `${CURL:-curl}` (the variable mirrors CMAKE so a control can name an absent program); `command -v` failing prints `no-curl` (exit 2).
8. `mkdir -p` the root; `tmp=$(mktemp -d "$root/.fetch.XXXXXX")`; then exactly the four-line trap idiom from scripts/check-traps.sh (EXIT removes the temp dir; HUP exits 129, INT 130, TERM 143).
9. `"$CURL"` (the program step 7 checked) with `--fail --silent --show-error --globoff --proto <p> --proto-redir <p> --max-redirs 5 --connect-timeout 20 --max-time 600 --max-filesize 268435456 --output "$tmp/payload" --url "$url"`; failure prints `download-failed: <dest>`.
10. `got` from `"${CMAKE:-cmake}" -E sha256sum`; mismatch prints `digest-mismatch: <dest>: pinned <want>, got <got>`.
11. `mkdir -p` the destination parent; compare `cd parent && pwd -P` with `cd root && pwd -P` (the parent must equal the root or sit below it): otherwise `symlink`; a symlink at the destination is `symlink`; a directory there is `dest-is-dir`.
12. `mv -f "$tmp/payload" "$root/$dest"`, print `fetch-pin: ok: <dest>`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pins.txt row -> shell and curl | Row text (digest, URL, dest) reaches a shell script and a network client |
| network or file source -> .fixtures/ | Downloaded bytes are untrusted until their digest matches |
| .fixtures/ -> git index | Fetched rights-bearing bytes must never be tracked |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-19 | Tampering | substituted or tampered download | high | mitigate | digest compared before `mv`; mismatch exits non-zero loudly with nothing placed (fetch.nc.digest_mismatch asserts no destination and no temp dir) |
| T-02-20 | Tampering, Information disclosure | downgrade or redirect to http or file | high | mitigate | `--proto` and `--proto-redir` restricted to the row's single scheme; `file://` only with GBL_FETCH_ALLOW_FILE=1 (control proves refusal without it); certificate checks left on |
