## Phase Goal

Planner framing of the existing goal, not a new owner decision: **As a** core implementer, **I want to** load an owned ROM into a deterministic machine and access memory through one timing-bearing bus, **so that** later CPU execution uses one safe, observable machine boundary.

<objective>
Make a real caller-owned machine perform EWRAM writes and reads through the final internal timing-bearing contract. Expand its executable checks to deterministic reset, independent instances, invalid arguments, and overflow. The first smoke witness extends the existing core.version executable so the leading tracer touches five files; dedicated behavior registrations immediately follow.
Purpose: establish the time/state seam Phase 4 consumes without promising a stable embedding ABI.
Output: lifecycle, bus contract, checked clock, behavior tests, and internal guide.
</objective>
